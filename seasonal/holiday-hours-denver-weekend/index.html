Read this before you rely on the table

These are regular weekend hours, not holiday hours. Holiday schedules can differ, and none of these businesses posted a special Thanksgiving schedule on the pages we checked on November 27, 2026. A short call before you leave is the only way to be sure a given location is staffed. Businesses that are not in this table are not closed; they simply did not have weekend hours we could verify from their own websites under the protocol described below.

How the verification works

Two independent passes read each business's own website without seeing each other's results. A set of hours counts as verified only when both passes record the same hours from visible text on the site. Availability slogans, call answering claims, and hours that appear only in page metadata do not count. Where the two passes disagreed, an adjudicator re-read the site and ruled; disputed businesses whose hours did not survive are not in the table. Directory hours and Google profile hours were never used.
